# AnimeAI-Chat

## Project Description
AnimeAI-Chat is a chatbot application that utilizes artificial intelligence to engage users in conversation about their favorite anime. It leverages natural language processing to provide relevant responses and enhance user interaction.

## Setup Instructions
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Bearkuma34/AnimeAI-Chat.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd AnimeAI-Chat
   ```

3. **Install the required dependencies**:
   ```bash
   npm install
   ```

4. **Start the application**:
   ```bash
   npm start
   ```

5. **Access the chat interface** in your browser at `http://localhost:3000`.
